Pick the tool before the code

What is happening → what owns the animation
Situation Tool Anchor
Press, toggle, focus withTiming · motion.fast You own a shared value
Release, settle, throw withSpring You own a shared value
Item mounts or unmounts entering / exiting Reanimated owns it
Item changes position or size layout Reanimated owns it
Finger drags something Gesture.Pan() writes, spring settles Gesture writes a shared value
Scroll drives an effect useAnimatedScrollHandler Scroll writes a shared value

Press feedback

Used by: button.tsx, any tappable plate. Motion: motion.fast.

Toggle

Motion: spring, no bounce. A toggle is a physical object moving, not a duration.

One anchor, many properties

The core of “complex” animation. Drive one number 0 → 1, derive everything from it.

Shake on invalid

Replaces the legacy Animated.sequence in code-field.tsx. Same timing, no JS thread.

Loop

Breathing seals, pending states. -1 repeats forever; true reverses each pass.

Message arrives, message leaves

Conversation list. No shared value: Reanimated owns the anchor. Build the configs at module scope.

Swipe to reply

Gesture Handler writes the anchor; a spring decides the resting place. The app already mounts GestureHandlerRootView.

Scroll drives a header

Masthead that fades as the ledger scrolls. Use Animated.ScrollView so the handler can run on the UI thread.

Reduced motion, and handing back to React

Timing and springs honour the OS setting by default. For decorative loops, check explicitly; to run JS from a worklet, hop back with scheduleOnRN.

Duration ladder

150 ms — press, toggle, focus.
250 ms — enter, exit, reorder.
400 ms — sheets, screens, large surfaces.

Traps

sv = 1 instead of sv.value = 1: nothing moves, nothing warns.

Reading .value during render: stale on purpose. Read it in a worklet.

Wrapping every property in its own withTiming inside useAnimatedStyle: animate one anchor, derive the rest.

Animating width or left: those cost layout. transform and opacity stay on the compositor.

Building FadeIn presets inside render: build them once, outside.

setState from a worklet: use scheduleOnRN.

One import rule

import Animated from "react-native-reanimated" is not the same import as React Native's Animated. Never hold both in one file; the compiler will not save you.
