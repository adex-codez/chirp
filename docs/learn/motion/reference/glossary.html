Reference / vocabulary

Motion glossary

One name per idea, used the same way in every lesson. If a term here disagrees with the Reanimated docs, the docs win and this page is wrong.

Anchor the idea this course is built on
The value an animation is built around. It outlives every frame, every render, and every animation function that writes to it. In Reanimated the anchor is a shared value; styles are derived from it, never written directly. One anchor can feed many style properties — that is the whole trick behind complex motion.

Lesson 01.

Shared value useSharedValue
A mutable box holding one value, readable and writable from both the JS thread and the UI thread. Created once per component with useSharedValue(initial), read and written through .value. Changing .value does not re-render React — that is the point.

It is not React state. useState describes what to render; a shared value describes where an animation is right now.

UI thread where frames are drawn
The main native thread that paints the screen. Reanimated runs animation functions and animated styles here, so motion continues while JavaScript is busy parsing JSON or running a query. JavaScript-driven animation (legacy Animated without the native driver) runs on the JS thread and stutters when that thread stalls.
Worklet a function allowed on the UI thread
A short function Reanimated can copy to the UI thread and run there — for example the callback passed to useAnimatedStyle. The Worklets Babel plugin (shipped by Expo) workletizes the callbacks Reanimated expects, so you rarely write the "worklet" directive yourself.

A worklet sees a copy of the values it closes over, not live JavaScript state. That is why props read inside an animated style behave like the value from when the style was created.

Animated component Animated.View
A component Reanimated can update outside React's render loop. Animated.View, Animated.Text, Animated.ScrollView are built in; anything else needs Animated.createAnimatedComponent (SVG elements, for example). A plain View holding an animated style will not animate.
Animated style useAnimatedStyle
A function from your anchors to a style object, re-run on the UI thread whenever an anchor changes. This is where interpolation and arithmetic live. Passing a shared value straight into style works for one-property cases, but cannot compute anything.

Use useAnimatedProps when the value is a prop (r on an SVG circle) rather than a style.

Animation function withTiming, withSpring, withDecay
A function that returns an animation object. Assign it to an anchor and the anchor travels to the target over time: pressed.value = withTiming(1). The result stored in the shared value is just the number.

withTiming is duration + easing — use it when the design system names a duration. withSpring is physics — use it when something is released, thrown, or handed off from a finger. withDecay is momentum after a flick.

Animation modifier withSequence, withDelay, withRepeat, withClamp
Functions that wrap an animation function to change its shape in time. withSequence chains steps (the shake in code-field.tsx), withDelay offsets a start, withRepeat loops, withClamp limits travel. Modifiers compose: a loop of a sequence is legal.
Interpolation interpolate
Mapping one numeric range onto another: interpolate(p, [0, 1], [0.96, 1]). It is the fan-out tool — one anchor, many style values. Pass Extrapolation.CLAMP so a spring overshoot does not push opacity past 1.
Derived value useDerivedValue
An anchor computed from other anchors. Use it when two animations need the same intermediate value, or when a gesture output needs normalising before three styles read it. If only styles read the value, compute it inside useAnimatedStyle instead.
Layout animation entering, exiting, layout
Animation owned by Reanimated rather than by you: a component fades in on mount, out on unmount, or slides when its position in a list changes. No shared value, no animated style. Presets such as FadeInDown and LinearTransition are configured with .duration() and .springify().

Docs recommend building these outside the component or with useMemo.

Gesture Gesture.Pan() + GestureDetector
A recogniser from react-native-gesture-handler whose callbacks run as worklets. The finger writes an anchor directly (x.value = event.translationX); an animation function takes over when the finger lifts. This is why gestures and Reanimated are taught together.
Reduced motion reduceMotion, useReducedMotion
The OS accessibility setting for less movement. Animation functions accept reduceMotion (default ReduceMotion.System), so timing and springs already honour the setting. Check it yourself with useReducedMotion() when an animation is decorative rather than informative.
Motion token motion.fast · base · slow
Chirp's named durations: 150 ms for state feedback (press, toggle), 250 ms for element transitions (enter/exit), 400 ms for large surfaces (sheets, screens). Tokens are the vocabulary; numbers in a lesson are examples of them.
JS→UI hop scheduleOnRN
A worklet cannot call setState. To hand a result back to React (send a reply, close a sheet), call scheduleOnRN(fn, args) from the worklet. Older code uses runOnJS, which still exists as an alias.

How to use this page

Skim before a lesson, return after. If you cannot say what the anchor is in a piece of motion code, the rest of it will not make sense.

Version notice

Reanimated 4 needs the New Architecture and the separate react-native-worklets package. Chirp has both. Code from a Reanimated 2 tutorial will mostly run, but setup advice will not.

Not in this glossary

CSS animations, Skia, Rive, shared element transitions. They are real, they are out of scope for the mission.
